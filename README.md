# Harmandeep — AI Engineer Portfolio

A minimalist, high-contrast **Y2K retro-futuristic & cyber-consciousness** portfolio designed for an **AI Engineer (Autonomous Agents, RAG Pipelines, MCP, LLM Orchestration)**.

---

## ⚡ Design Philosophy & Aesthetic Blueprint

- **Typography:** Hard-ending, bold geometric sans-serif (`Syne` & `Space Grotesk`) and monospace (`JetBrains Mono`). Strictly zero cursive or trailing scripts.
- **Color Palette:**
  - Base Obsidian Dark: `#121312` / `#1E1F1E`
  - Neon Cyber Pink: `#F387A1`
  - Pastel Blush Pink: `#F7BFCB`
  - Metallic Chrome Silver: `#C5C5C5` & `#E5E5E5`
- **Textual Golden / Fibonacci Proportions:** Layout hierarchy optimized for readability, breathing room, and high contrast.
- **Visuals & Art Elements:**
  - **Evolving Eye of Consciousness:** Interactive SVG/Canvas merging Sacred Yogic geometry (Merkaba, concentric mandalas) with pupil gaze tracking and cybernetic matrix rings.
  - **Vintage Y2K CRT Mind-Altering Scanline Filter:** Toggleable phosphor CRT effect with subtle cathode ray flicker.
  - **Secret Agency Dossier & Terminal:** Interactive classified terminal supporting `identity`, `projects`, `eval`, `mcp`, `status`, and `matrix` commands.
  - **Ephemeral Binary / Hash Triggers:** Interactive codes in square brackets (e.g. `[0x7F::SYNAPSE]`, `[MCP::STDIO_CLIENT]`, `[0x9B::HIT@K_BENCHMARK]`) that decrypt cryptic transmissions upon click and smoothly fade out.
- **Mobile Friendly:** Fully responsive navigation dock, fluid touch interactions, and adaptive grid sizing down to 320px.

## 🚀 Getting Started

### Local Development
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build
```bash
npm run build
```
Creates an optimized static bundle in `./dist`.

### Deployment & CI/CD
Automated continuous integration and deployment via GitHub Actions on every push to `main`, publishing live to [Cloudflare Pages](https://harmandeep-portfolio.pages.dev).

```bash
npm run deploy
```
Deploys directly to Cloudflare Pages via Wrangler CLI.

### Preview Build
```bash
npm run preview
```
